# Вишлист v2 — макеты

Стиль повторяет текущий сайт MySanta (Inter, зелёный `#27AE60` / красный `#f74f4f`,
мятные панели, радиус 10px). **Это макеты** — бэкенда нет, ничего не сохраняется.

| | Открыть | Что это |
|---|---|---|
| **Интерактивный прототип** | [`index.html`](index.html) | Полноценное «приложение» с живой навигацией: страницы открываются из меню и по ссылкам внутри экранов. Это корень сайта. |
| **Презентация** | [`presentation/index.html`](presentation/index.html) | Сценарии по ролям: подпись + живой экран, проигрывается сама. Лежит на `/presentation/`. |

**Экраны у обеих страниц общие** — один и тот же код (`app-core.js`), поэтому они совпадают
пиксель-в-пиксель. Различаются только оболочки: у презентации — подписи и перелистывание,
у прототипа — сайтовая навигация.

## Как открыть

Открыть нужный `index.html` в браузере. Сборки нет. Vue лежит локально в `vendor/`.
Товары — реальные из каталога MySanta (mr_geek), картинки грузятся с `storage.mrgeek.ru`
(нужен доступ в сеть; при ошибке загрузки — плейсхолдер).

Сайдбар прототипа — точная копия `app/frontend/.../components/Aside` с плейсхолдерными
данными; сворачивается кнопкой-язычком, как в проде.

## Раскладка и навигация в прототипе

Прототип повторяет раскладку MySanta: слева — сайдбар MySanta
(логотип, пользователь, «Главное меню», «Вишлист», «Санта AI», «Создать игру», «Поддержка»),
справа от него — раздел «Вишлист». На экране «Идеи подарков» справа стоит панель списка,
как на настоящем сайте.

Сайдбар — точная копия `components/Aside` с оригинальными PNG-иконками
(`wishlist-v2/icons/`, взяты из `assets_sources/src/icons/png`). Пункт **«Вишлист»**
ведёт в раздел, остальные — заглушки MySanta. Сворачивается язычком, как в проде.

Навигация внутри раздела, без ролей-переключателей:

- Домашняя страница — **Идеи**. Вкладки: **Идеи** · **Мои списки** · **Активность**.
- Под вкладками — видимый **переключатель списков** (пилюли с эмодзи и счётчиком, «＋», «Поделиться»).
- Ссылка **«Открыть, как список видит даритель»** ведёт на экран дарителя; оттуда «Скинуться» — на совместный сбор; назад — по хлебным крошкам.
- Уже 960px сайдбар прячется, контент занимает всю ширину.

## Файлы

- `app-core.js` — общее ядро: реактивное состояние, действия и **все экраны** (компоненты `GiftCard`, `GiftRow`, `AddGiftForm`, `Thumb` + экраны). Никакого дублирования разметки.
- `styles.css` — визуальный язык экранов (общий).
- `shell.css` — оболочки: навигация прототипа и колода презентации.
- `pics.js` — карта картинок товаров (URL + запасной URL).
- `index.html` + `prototype.js` — прототип, корень сайта.
- `presentation/index.html` + `presentation/presentation.js` — презентация.
- `vendor/vue.global.prod.js` — Vue 3.5, локально.
